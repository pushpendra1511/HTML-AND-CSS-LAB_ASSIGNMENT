Aim
Make tables with caption, head, body and foot, and make them accessible.

Theory
- <table> holds data in rows (<tr>), header cells (<th>) and data cells (<td>).
- <caption> is the title of the table.
- <thead>, <tbody> and <tfoot> group the header, body and footer rows.
- scope="col" or scope="row" on <th> tells screen readers whether the header applies to a column or a row.
- Class average: Maths = (78 + 64) / 2 = 71, Science = (85 + 70) / 2 = 77.5.
