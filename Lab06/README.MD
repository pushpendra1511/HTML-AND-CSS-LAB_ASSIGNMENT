Aim
Create unordered, ordered, nested and description lists.


Theory
- <ul> is an unordered list (bullets). <ol> is an ordered list (numbers). Each item uses <li>.
- Nested list: a list placed inside an <li> of another list. It must be inside the <li>, not directly inside <ol>.
- <dl> is a description list: <dt> is the term (question) and <dd> is its description (answer).
- Lists give a page structure and are read properly by screen readers.
