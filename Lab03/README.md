Aim
Write a basic HTML page, then use headings, paragraphs, bold, italic and line breaks.


Theory
- HTML (HyperText Markup Language) describes the structure of a web page using elements made of tags, like <p>text</p>.
- Basic skeleton: <!DOCTYPE html>, <html>, <head> (title, meta) and <body> (what the visitor sees).
- <title> is shown on the browser tab. <meta charset="UTF-8"> allows all characters.
- Headings go from <h1> (most important) to <h6>. Use one <h1> per page.
- <p> makes a paragraph. <strong> means important text (bold), <em> means emphasis (italic).
- <br> is a void element: it has no closing tag and just breaks the line.
