Aim
Use div containers, id/class/data attributes and fix a broken page.


Theory
- <div> is a generic block container. It groups content so it can be styled or positioned.
- Attributes give extra information to a tag: id, class, data-*.
- id must be unique on a page. class can be reused on many elements.
- data-* attributes store custom data, for example data-topic="hobbies".
- Nesting means putting one element inside another. Tags must close in the reverse order they opened.
- Browsers forgive many mistakes, but unclosed or wrongly closed tags give unpredictable layout. Validators help to find them.
