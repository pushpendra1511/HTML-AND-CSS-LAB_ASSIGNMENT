Aim:
Build a navigation bar and rows of cards with Flexbox.

Theory:
- Flexbox lays items out in one direction (a row or a column). Enable it with display: flex on the parent.
- Main axis is the direction of the row. Cross axis is perpendicular to it.
- justify-content aligns items along the main axis (e.g. center, space-between). align-items aligns along the cross axis.
- gap sets the space between items.
- flex-wrap: wrap lets items move to the next line when there is not enough space.
