Aim
Build a page using semantic elements, in-page links and an email link.

Theory
- Semantic elements describe their meaning: <header> (top of page), <nav> (navigation links), <main> (main content), <section> (a topic block), <footer> (bottom).
- They are better than many plain <div>s for accessibility and search engines.
- Fragment link: <a href="#about"> jumps to the element that has id="about" on the same page.
- Email link: <a href="mailto:name@example.com"> opens the mail app.
